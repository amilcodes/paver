What the measurements say
Errors use only hidden patches whose original pixels are known. Accepted-pixel comparisons use exactly the same pixel set for both methods. Full-mask errors also count the unresolved dark holes.

MAE is mean absolute RGB error on a 0–255 scale; lower is better. Pinhole-space measurements, one drive, four development masks. The wider field of view was chosen after inspecting the first run; this is not an independent test set. Simple inpainting wins on full-mask error in these checks because it fills every pixel, including where the geometric method abstains.

The next experiment
Collect a small, route-separated benchmark with known ground truth, then compare stronger correspondence methods and calibrated depth against this baseline. Measure accepted coverage and wrong-transfer rate together. Moving cars and non-planar surfaces need explicit visibility reasoning before they enter the repair scope.
Closest prior work already includes multi-view urban inpainting (2016) and street-view depth-based object removal (2019). The candidate research contribution is measurable reliability under sparse, imperfect panoramas; novelty is not established.
