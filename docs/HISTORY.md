# Reconstructed history

There was no existing Git commit history when this repository was prepared.
The historical author dates reflect the recorded modification times of the
surviving project files on **2026-10-31 UTC**. Commits group those current file
versions into chronological milestones. Each milestone's author time is the
latest recorded modification time among its files; its committer time is the
actual import time. New publication tooling and documentation are dated now.

This does **not** recover intermediate versions, prove exact original creation
times, or claim the project existed before the recorded day. An early commit
may not run on its own if a dependency's only surviving version was edited
later. The complete snapshot is the reproducible unit.

`publication/snapshot.jsonl` records original paths relative to the research
root, source timestamps, original/exported SHA-256 values and storage location.
`publication/history.json` records the reconstructed milestone boundaries.
Failed experiments, nonconvergence, unchanged controls and rejection decisions
are included alongside successes.
